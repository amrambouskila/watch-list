# Card artwork sources

Every image here came from Wikimedia Commons under a free licence (public domain, CC0, or
CC BY). Each was cropped to the mark; where the original was dark line art it was recoloured,
and where it carried a solid background that background was removed, so each reads on a dark
card.

To use a different image for a category, drop your own file in this folder named after the
category id (for example naruto-comprehensive-master-watch-order.jpg). Renaming a category
changes its id, so rename the image to match.
